# BIGTREETECH Pi TFT50 V2.1

Комплект дисплея для Radxa Dragon Q6A с Radxa OS R2 и ядром `7.0.11-7-qcom`.
Один оверлей включает питание LCD на GPIO80, панель DSI 800×480, подсветку
и контроллер касаний. В комплект также входит драйвер `edt-ft5x06`
с опросом каждые 17 мс и исправлением обработки контактов.

Скопируйте каталог [target/sbc/radxa_dragon_q6a](target/sbc/radxa_dragon_q6a/)
целиком на Q6A. В этом каталоге выполните от обычного
пользователя:

```sh
sh setup.sh
```

Установщик показывает прежние профили перед заменой. Enter отменяет замену,
`--replace` подтверждает её заранее. `sh setup.sh --plan` показывает план.
При нескольких загрузочных записях без однозначного default передайте
`--entry /boot/efi/loader/entries/ИМЯ.conf`.

На плате проверены изображение, подсветка и точность одиночного касания с
прежней парой оверлеев. Единый DTBO даёт то же нормализованное дерево на
DTB этого ядра, включая конфигурацию с тремя камерами. Перезагрузка с новым
комплектом на физической Q6A остаётся открытой проверкой.
